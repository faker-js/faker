### Removal of legacy `cell_phone` locale definitions

The legacy `cell_phone` locale definition category has been removed. There was never a `faker.cell_phone` module; these definitions could only used directly via `definitions.cell_phone` in selected locales.

Use [`faker.phone.number()`](https://fakerjs.dev/api/phone.html#number) with `{ style: 'mobile' }` instead:

```ts
// v10
faker.helpers.replaceSymbols(faker.helpers.arrayElement(fakerEN_GB.definitions.cell_phone.formats));

// v11
fakerEN_GB.phone.number({ style: 'mobile' });
```
