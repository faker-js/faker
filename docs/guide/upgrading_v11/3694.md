### `faker.person.sexType()` now includes `'generic'` by default

The `includeGeneric` option of `faker.person.sexType()` now defaults to `true`, so calling `faker.person.sexType()` without options can return `'female'`, `'male'` or `'generic'`.

This also affects methods that pick a random sex type when no sex is provided, such as `faker.person.firstName()`, which may now select entries from the `generic` definition lists.

To keep the previous behavior, pass `{ includeGeneric: false }` explicitly:

```ts
// v10
faker.person.sexType(); // 'female' or 'male'

// v11
faker.person.sexType(); // 'female', 'male' or 'generic'
faker.person.sexType({ includeGeneric: false }); // 'female' or 'male'
```
