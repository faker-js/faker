### `faker.helpers.mustache` matches placeholder keys literally

Previously, each key of the `data` object was inserted into a regular expression without escaping, so keys containing RegExp syntax (such as `.`, `$`, `(`, `[`, `+` or `|`) either failed to replace their own placeholder or replaced other placeholders. Keys are now matched literally: a key only replaces the exact `{{key}}` placeholder.

```ts
// v10
faker.helpers.mustache('{{user.name}} {{userXname}}', { 'user.name': 'Ann' }); // 'Ann Ann'
faker.helpers.mustache('{{price($)}}', { 'price($)': '5' }); // '{{price($)}}'

// v11
faker.helpers.mustache('{{user.name}} {{userXname}}', { 'user.name': 'Ann' }); // 'Ann {{userXname}}'
faker.helpers.mustache('{{price($)}}', { 'price($)': '5' }); // '5'
```

If you relied on a key being treated as a regular expression, replace the placeholders with `String.replace()` yourself:

```ts
// v10
faker.helpers.mustache(text, { '[^}]+': (match) => lookup(match) });

// v11
text.replace(/{{[^}]+}}/g, (match) => lookup(match));
```
